Исследование распараллеливания операции умножения квадратных матриц.
Языки: C++23 (с модулями), Python (для верификации).

## Этапы

- **Лабораторная работа №1** — Последовательный алгоритм *(_на проверке_)*
- **Лабораторная работа №2** — OpenMP *(_на проверке_)*
- **Лабораторная работа №3** — MPI *(в разработке)*
- **Лабораторная работа №4** — CUDA *(в разработке)*

## Идея

Задача одна на все этапы — перемножение двух квадратных матриц `A × B`.
Меняется только способ вычисления: от последовательного к параллельному
через разные технологии. Всё остальное (I/O, генерация данных, проверка
результата) переиспользуется между лабами.

## Структура

```
<repo>/
└── labN/
   ├── cpp/            исходники на C++23 (модули)
   ├── data/           входные и выходные матрицы
   └── py/             скрипт верификации через numpy
```

## Требования к системе

- CMake 3.28+
- Компилятор C++23: MSVC 19.40+ / GCC 14+ / Clang 17+
- Python 3.10+ с NumPy
- (Опционально) Visual Studio 2022 для MSVC

## Замечания

- Матрицы хранятся как плоские текстовые файлы — одно число на строку.
  Это позволяет читать их и в C++ без лишних зависимостей, и в numpy через `np.loadtxt`.
- Верификация результата делается через `numpy`: считаем `A @ B` и сравниваем
  с тем, что записала C++ программа.
- Для запуска экспериментов размер и число потоков передаются аргументами командной строки.
